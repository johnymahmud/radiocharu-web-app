📖 Quick Encoder Setup Guides
🎧 BUTT (Broadcast Using This Tool) Setup ▼

1. Open BUTT $\rightarrow$ Click Settings $\rightarrow$ Main $\rightarrow$ Server Add.

2. Configure: Type: Icecast | Host: localhost | Port: 8000

3. Mount: /live | User: source | Password: Paste the source password above.

4. In the Audio tab: Choose MP3 at 192 kbps (or 128 kbps), 44.1 kHz Stereo. Click Play (▶) on the main BUTT window to go live.

🎛️ Mixxx DJ Live Broadcasting Setup ▼

1. Open Mixxx $\rightarrow$ Options $\rightarrow$ Preferences $\rightarrow$ Live Broadcasting.

2. Set Type: Icecast 2, Host: localhost, Port: 8000, Mount: /live.

3. Set Login: source and paste your Password.

4. Press Ctrl + L in Mixxx to activate live broadcasting.

📱 Mobile Encoders (BroadcastMySelf / Rocket Broadcaster) ▼

For live broadcasting from Android or iOS, enter the server parameters above into BroadcastMySelf or Rocket Broadcaster.
